## Applications

- **[FIX Parser](https://fixparser.targetcompid.com)** (since 2012): a well-known, highly regarded tool for reading FIX messages, used by thousands of people every month: detects the delimiter automatically (SOH, pipe, comma, etc.), preserves message order and supports filters.
- **[FIX Tester](https://fixtester.targetcompid.com)**: a hosted FIX server to test a FIX engine against. Users log on, send test orders, and acknowledge, fill or reject them from the page.
- **[Agent Debugger](https://agentdebugger.sh)**: shows what a coding agent actually did, with every read, retry and wasted step in a Claude Code, Codex or GitHub Copilot session.
- **[Skill Tracer](https://shahbazac.com/skills/)**: a reference to how professionals write agent skills. Over 900 skills, each annotated with what triggers it and how it connects to the others; a model drafts the notes, and every quote is checked against the skill's own text.
- **[Interactive Trainer](https://trainingdata.fit)**: builds training labels when there is no ground truth. The user marks a few examples on a 2D map of the data, and it ranks every remaining row for review.
- **[Class Planner](https://classplanner.io)**: plans a course by what depends on what, flagging any topic taught before its prerequisites and any class that runs over time.
- **[postcell.io](https://postcell.io)** (since 2020): a Jupyter plugin and website for real-time review of, and feedback on, students' in-class assignments.
- **[SQL Forever](http://sqlforever.com)** (since 2020): lets students practice SQL without installing a database on their own machines.
